USDb is a USD-pegged stablecoin on the [Rootstock](https://rootstock.io)
network, backed 1:1 by USDC on Ethereum. The USDb API lets you convert a
company's USDC into USDb and back, and manage the wallets that hold them.

## What you can do

- **Request wallets** for USDC (Ethereum) and USDb (Rootstock).
- **Mint USDb** by converting a company's USDC into USDb.
- **Burn USDb** to convert it back into USDC.
- **Withdraw** crypto from a wallet to an external address.
- **Track activity** through wallet transactions and webhooks.

## Authentication

All USDb endpoints support **API key authentication only**. Include your
access token as a Basic credential:

```
Authorization: Basic <ACCESS_TOKEN>
```

OAuth 2.0 bearer tokens are not accepted on these endpoints. See the
[Authentication guide](/guides/authentication) for how to obtain an API key.
