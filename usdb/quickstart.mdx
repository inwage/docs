This quickstart walks you through minting USDb end to end: authenticate,
provision the wallets, mint USD into USDb, and confirm completion with a
webhook.

## Prerequisites

Before you begin, make sure you have:

- A **Bitwage Business Account** with an [API key](/usdb/authentication).
- A **company** that has completed KYC and is provisioned for USDb.
- A tool for making HTTP requests, such as `curl`.

<Note>
Use the sandbox environment (`https://api.sandbox.bitwage.com`) while you build
and test. Switch to production (`https://api2.bitwage.com`) only when you are
ready to move real funds.
</Note>

## Step 1: Authenticate

USDb endpoints use API key authentication only. Pass your access token as a
Basic credential on every request:

```bash
curl "https://api.sandbox.bitwage.com/api/wallets?company_id=YOUR_COMPANY_ID" \
  -H "Authorization: Basic YOUR_ACCESS_TOKEN"
```

## Step 2: Request your wallets

Minting moves funds between two wallets the company owns: a USD wallet and a
USDb wallet on Rootstock. Request each one. The USDb wallet requires a `rail`;
the USD wallet is a fiat balance account and takes no rail.

```bash
# USD (the settlement asset you mint from)
curl -X POST "https://api.sandbox.bitwage.com/api/wallets/request" \
  -H "Authorization: Basic YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: 11111111-1111-1111-1111-111111111111" \
  -d '{ "company_id": "YOUR_COMPANY_ID", "currency": "USD" }'

# USDb on Rootstock (the stablecoin)
curl -X POST "https://api.sandbox.bitwage.com/api/wallets/request" \
  -H "Authorization: Basic YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: 22222222-2222-2222-2222-222222222222" \
  -d '{ "company_id": "YOUR_COMPANY_ID", "currency": "USDB", "rail": "ROOTSTOCK" }'
```

Provisioning is asynchronous. Each wallet emits a `wallet.request` webhook when
it reaches a terminal status.

## Step 3: Confirm the wallets are active

List the company's wallets and note the `id` of each. You need both IDs for the
mint, and both must have a `status` of `active`.

```bash
curl "https://api.sandbox.bitwage.com/api/wallets?company_id=YOUR_COMPANY_ID" \
  -H "Authorization: Basic YOUR_ACCESS_TOKEN"
```

```json Response
{
  "wallets": [
    { "id": "custodial_account_usd", "currency": "USD", "status": "active", "balance": "500.00", "is_default": false, "is_available_for_payroll_funding": true },
    { "id": "custodial_account_usdb", "currency": "USDB", "status": "active", "balance": "0.00", "is_default": false, "is_available_for_payroll_funding": true }
  ]
}
```

## Step 4: Mint USDb

Convert USD into USDb. The source is your USD wallet; the destination is your
USDb (Rootstock) wallet. The minimum amount is `10`.

```bash
curl -X POST "https://api.sandbox.bitwage.com/api/wallets/mint" \
  -H "Authorization: Basic YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: 33333333-3333-3333-3333-333333333333" \
  -d '{
    "company_id": "YOUR_COMPANY_ID",
    "from_account_id": "custodial_account_usd",
    "to_account_id": "custodial_account_usdb",
    "amount": "100.00"
  }'
```

```json Response
{
  "status": "initiated"
}
```

## Step 5: Confirm completion

A `status` of `initiated` means the mint was accepted, not that it has settled.
Wait for the `wallet.mint` webhook to confirm the conversion is final.

```json wallet.mint webhook
{
  "event": "wallet.mint",
  "data": {
    "company_id": "YOUR_COMPANY_ID",
    "status": "completed",
    "from_currency": "USD",
    "to_currency": "USDB",
    "amount": "100.00",
    "from_wallet_id": "custodial_account_usd",
    "to_wallet_id": "custodial_account_usdb",
    "send_tx_hash": null,
    "deposit_tx_hash": "0xdef..."
  }
}
```

When you receive `status: "completed"`, the USDb balance is available in the
destination wallet.

## Summary

You authenticated, provisioned USD and USDb wallets, minted USDb, and
confirmed the result with a webhook. Key points to remember:

- **API key only** — USDb endpoints reject OAuth bearer tokens.
- **Idempotency required** — every write needs a unique `Idempotency-Key`.
- **Asynchronous** — treat the `wallet.mint` / `wallet.burn` webhook as the
  source of truth for completion, not the initial response.
- **$10 minimum** — amounts are major-unit strings.
