USDb is an [ERC-20](https://eips.ethereum.org/EIPS/eip-20) token deployed on the
[Rootstock](https://rootstock.io) network. Use the addresses below to verify
balances on-chain, receive USDb to an external wallet, or integrate USDb into
your own tooling.

<Warning>
  Always confirm you are using the correct contract address and network. Tokens
  sent to the wrong address or an unsupported network **cannot be recovered**.
  Verify every address against this page before transacting.
</Warning>

## Token details

| Property | Value |
|---|---|
| Name | `Bitcoin USD` |
| Symbol | `USDB` |
| Decimals | `6` |
| Standard | ERC-20 (with [EIP-2612](https://eips.ethereum.org/EIPS/eip-2612) `permit`) |
| Network | Rootstock (RSK) |

<Note>
  USDb uses **6 decimals** — `1 USDB = 1000000` base units. Account for this
  when reading on-chain balances or constructing transfers.
</Note>

## On-chain transfers

USDb is a standard ERC-20, so it works with any ERC-20-compatible wallet,
library, or contract. Transfers, approvals, and `permit`-based gasless
approvals behave exactly as they do for other ERC-20 tokens — point your tooling
at the contract address for the relevant network and use 6-decimal amounts.

Gas on Rootstock is paid in **RBTC** (the network's native token), not in USDb.
A wallet needs a small RBTC balance to broadcast a transfer.

<Note>
  For minting, burning, and Bitwage-custodied wallets, use the
  [USDb API](/usdb/quickstart) rather than interacting with the contract
  directly — Bitwage manages those wallets and sponsors their network fees.
</Note>
